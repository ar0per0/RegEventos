# RegEventos
[Google Play](https://play.google.com/store/apps/details?id=es.aropero.regeventos&utm_source=emea_Med)

**RegEventos** es una aplicación Android diseñada para registrar de forma rápida y sencilla
acciones que ocurren durante un evento, actividad o jornada.

La aplicación permite crear botones personalizados para las acciones que se realizan
habitualmente. Al pulsar uno de estos botones, la acción queda registrada automáticamente
con la fecha y hora en la que se ha producido.

También es posible crear campos de texto personalizados para introducir información
adicional y guardarla junto con el registro.

De esta forma, RegEventos permite llevar un registro cronológico de lo que ocurre durante
una actividad sin tener que escribir manualmente cada acción.

## ✨ Características

### ⚡ Registro rápido

Puedes crear tus propios botones de acciones y colocarlos en el orden que prefieras.

Por ejemplo:

- Inicio
- Pausa
- Cambio
- Incidencia
- Finalización

Al pulsar un botón, la acción se registra automáticamente con la fecha y hora actual.

### 📝 Campos personalizados

Además de las acciones rápidas, puedes crear campos de texto personalizados para
introducir información durante el evento.

Por ejemplo:

- Nombre
- Número
- Observaciones
- Resultado
- Descripción

Cada campo puede utilizarse para introducir información y añadirla al registro con un
solo toque.

### 📅 Historial de eventos

Todos los registros se almacenan con su fecha y hora.

Puedes consultar los registros de un día concreto o visualizar todos los registros
disponibles.

También puedes seleccionar un registro para modificar su texto, hora o descripción,
o eliminarlo si es necesario.

### 📤 Exportación

Los registros pueden exportarse en un archivo ZIP y compartirse mediante las aplicaciones
disponibles en el dispositivo.

Esto permite guardar una copia de los datos o enviarlos a otro dispositivo o servicio.

### ⚙️ Configuración

RegEventos permite personalizar:

- Acciones rápidas.
- Campos de texto.
- Orden de las acciones.
- Orden de los campos.
- Tema de la aplicación.
- Idioma de la aplicación.

### 🧩 Widget

La aplicación incluye un widget de Android para facilitar el acceso a las acciones
desde la pantalla de inicio.

### 🌙 Tema e idiomas

RegEventos permite utilizar:

- Tema claro.
- Tema oscuro.
- Tema según la configuración del sistema.

La aplicación está disponible en:

- 🇪🇸 Español
- 🇬🇧 English

## 🔒 Privacidad

Los datos de RegEventos se almacenan localmente en el dispositivo.

La aplicación no requiere una cuenta de usuario para utilizar sus funciones principales.
